Recruitment Request

Streamlined hiring requests with role‑based approvals, signatures, stage uploads, and automated email triggers.
Odoo 17 HR / Recruitment Multi‑Company & Rule‑Based License: LGPL‑3 or OPL‑1

Overview

Recruitment Request provides a clear, auditable hiring request flow: raise a request from a department user, obtain HR and CAO approvals, and let HR create the recruitment record. Designed for multi‑company environments with configurable rules and automated notifications at every stage.

Approval Workflow

Raise (Dept User) HR Approval CAO Approval HR: Create Recruitment

Each stage supports: signature, date, file upload, and an automatic email trigger (configurable template per stage).

Key Features

✅ Raise Request (Department)

Department user fills role details, justification, cost centre, and attachments.

✉️ HR & CAO Email Triggers

Configurable templates fired on submit, HR approve/reject, CAO approve/reject, and when HR creates the recruitment position.

🖋 Stage Signatures & Uploads

Record signature (binary or e‑sig), signed date, and allow file uploads at every approval stage.

🌐 Multi‑Company / Rule‑Based

Company‑aware rules: route based on company, department, role seniority or cost thresholds.

⚙️ HR: Create Recruitment

After approvals, HR can convert the request to a recruitment record (job, requisition, or vacancy) with one click.

Implementation Notes

  • Role‑based access control: use record rules for Dept User, HR, and CAO per company.
  • Email templates: create a template per stage and wire them to server actions or automated activities.
  • Signatures: store binary signatures and signed date fields on the request; optionally integrate e‑sign services.
  • Attachments: use a one2many to store uploaded files per stage for audit.
  • Conversion action: provide a smart button for HR to convert request → recruitment/job opening.
