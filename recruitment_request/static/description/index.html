Recruitment Request Workflow

Overview

The Recruitment Request Workflow module streamlines the employee recruitment initiation process in Odoo. It ensures a smooth, multi-stage approval chain — from the department user to HR, CAO, and finally HR recruitment creation. Each stage captures signatures, records signed dates, stores attachments, and sends automatic email notifications. Designed for multi-company setups with strict role-based access.

Features

  • Stage-based workflow: Raise Request → HR Approval → CAO Approval → HR Creates Recruitment.
  • Signature, date, and attachment capture at every stage.
  • Automated email notifications with CC support at each stage transition.
  • Multi-company ready with role-based access rules.
  • Direct HR action to create Odoo Recruitment records from approved requests.
  • Integrated with hr_recruitment and mail for seamless operation.

Usage

To use the Recruitment Request Workflow module, follow these steps:

  1. Install the module in your Odoo 17 instance.
  2. Define roles for Department User, HR, and CAO in Security Settings.
  3. Create a recruitment request from the department dashboard.
  4. Follow the approval flow with digital signatures and attachments at each stage.
  5. Upon CAO approval, HR can create a Recruitment record directly from the request.

Compatibility

Compatible with Odoo 17 (Community & Enterprise).
