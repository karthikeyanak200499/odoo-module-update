Overview

Employee Exit Form adds a clear, auditable exit process with role‑based access and automated notifications. Designed to be light on dependencies and easy to maintain.

Key Features

✅ Role & Company Aware

Record rules for User / Dept Head / HR / CAO; multi‑company ready.

✉️ Email Triggers

Templates for submit, HR forward, CAO approve/reject with CC support.

🖋 Signatures

Binary signatures and dates for Employee, HR, and CAO.

📦 Asset Returns

One2many for items, serials, and return dates; printable friendly.

⚙️ Smart Actions

Proceed to HR, archive & open employee, auto defaults & computed texts.
